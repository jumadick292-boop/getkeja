# Task 13.7 — Garbage Collection Operations: Pre-Implementation Audit

## Dual provider model reconciliation (Task 13.1 finding)
- **Legacy**: `garbage_providers` (org-linked, own `garbage_provider_status`,
  `garbage_collection_requests`, `garbage_provider_assignments`) — used by the
  tenant `/api/v1/tenant/garbage-requests` flow and landlord assignment screens.
- **Authoritative (13.3)**: `specialized_profiles` (`profile_category =
  garbage_collection_provider`) + `organisations`/`organisation_members` +
  `role_assignments`/`role_permissions`.
**Decision**: `specialized_profiles` + orgs is the single authoritative provider
identity. Legacy garbage tables/endpoints remain for backward compatibility but
no new provider accounts or request engines are created. New garbage operations
build on the 13.5 marketplace (service_requests/quotations) and the 13.6 moving
operational pattern.

## Reused (extended, not duplicated)
- Marketplace `service_requests`/`service_quotations` (accepted quotation =
  contractual snapshot), `service_categories` (garbage_* + recycling), offerings,
  capabilities, `saved_locations`, `provider_service_areas`.
- 13.6 patterns: job-from-accepted-quotation, validated lifecycle + history,
  staff assignments with explicit `provider.*` permissions, completion +
  customer confirmation, transactional outbox.
- `properties`/`units`/`tenancies` + `unit_occupancy_history` for property/
  tenancy authorization (server-side relationship checks; never trust client
  property IDs).
- pg-boss (cron) for the idempotent recurring occurrence generator; outbox for
  notifications; loose `document_id` attachments.

## New structures (additive)
- `garbage_jobs` (operational collection; UNIQUE per accepted request OR per
  recurring occurrence), `garbage_job_history`, `garbage_job_staff_assignments`,
  `garbage_job_attachments`, `garbage_job_exceptions`.
- `garbage_recurring_agreements` (customer preference → provider proposal →
  customer-approved agreement; frequency, days, windows, start/end, status) and
  `garbage_recurring_occurrences` (UNIQUE(agreement_id, period_key)) generated by
  an idempotent pg-boss worker (Africa/Nairobi, missed-run safe, suspension/
  cancellation respected, no rewrite of history).
- `garbage_collection_status`, `garbage_agreement_status`,
  `garbage_occurrence_status` enums; `provider.garbage.*` permissions.

## Out of scope (later tasks)
Fleet/vehicles, drivers, live GPS, route optimization, dispatch, payments/
payouts/commission, transfer stations, processing plants, regulatory reporting,
reviews/ratings, full dispute resolution. Hazardous/regulated waste requires
provider verification (not enabled by a label alone).
